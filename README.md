# Java OOP — Abstract Shape Calculator 

Demonstrates core OOP concepts in Java through a clean Shape hierarchy.

## What's covered
- Abstract classes & methods
- Constructors with super()
- Method inheritance & overriding
- Runtime polymorphism (getSimpleName, area dispatch)
- Array of superclass references

## Classes
- Shape (abstract) → Circle, Rectangle

## Run it
Compile and run Main.java — no dependencies needed.
